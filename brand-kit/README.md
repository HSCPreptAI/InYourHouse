# In Your House brand kit

Open `index.html` in a browser for the full guide: logo system, colour, type, tone of voice, imagery and theme tokens.

Shopify only syncs the theme folders (`assets`, `config`, `layout`, `locales`, `sections`, `snippets`, `templates`), so this folder stays in the repo and never reaches the store.

| Folder | Contents |
| --- | --- |
| `logos/` | IYH monogram (desktop logo: master on black, ink and cream cut-outs), wordmark and `!` mark in black and white, transparent PNG, plus padded wordmark versions |
| `icons/` | 512px app icons, 180px web clip, 64px favicon |
| `social/` | 1200×630 link preview, 1080px Instagram avatar and wordmark post |

Fonts live in the theme's `assets/` folder: `NeueHaasDisplay-Mediu.woff2`, `NHaasGroteskTXPro-55Rg.otf`, `VCR_OSD_MONO_1.001.ttf`. They're licensed fonts, so check the licence before using them anywhere new.

Source logos: the IYH monogram supplied in chat, and `"!" LOGO SAMPLES/logo png` in the INYOURHOUSE Drive folder for the wordmark.
